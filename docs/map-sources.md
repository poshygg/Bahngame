# Geography and German content pack

Checked on 13 September 2026. The game uses real WGS84 locations on a geographic basemap. The coloured journey line joins station locations schematically: it does **not** reproduce railway track geometry, platforms, tunnels, walking access, journey times or current service availability. Landmark cards describe places near a station, not sights necessarily visible through a train window.

## Content structure

- `src/data/geography.ts` defines the country-independent geographic contract.
- `src/data/packs/germany.ts` contains ordered station locations and nearby landmark references.
- `src/data/packs/germany-landmarks.ts` contains the shared, English/German landmark content.
- `src/data/stages.ts` adds game metadata and derives `origin` / `stations` from each route. A station's typing name and map position therefore cannot drift into separate lists.

To add a city, provide an ordered `RouteStop[]`, verify its connections against an operator's network, attach nearby landmarks, then register a stage. To add a country, add its pack and country registry entry; the map and scoring engine do not need city-specific code. Interface language is independent of geographic content.

## Station coordinates and licensing

Station locations and landmark point locations were retrieved from OpenStreetMap through [Overpass API](https://overpass-api.de/api/interpreter). The source is [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), licensed under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/).

Every station includes the exact OSM feature URL in `sourceUrl`. Landmarks retain their OSM feature URL in `coordinateSourceUrl`, separately from the tourism page supporting their description. Node coordinates are used directly; for ways/relations, the Overpass bounding-box centre is used. These are representative station/sight positions, not entrance-level navigation data. Names omit optional network prefixes and some parenthetical secondary labels to keep typing readable.

The small derived geographic subset is included in the source files and retains OSM attribution. Live basemap tiles have their own provider attribution and usage requirements; the renderer keeps attribution visible. No provider map image, tourism photograph or article has been copied into the content pack. Landmark descriptions are short original summaries.

## Calm geographic basemap

Version 0.3 uses the [OpenFreeMap public vector service](https://openfreemap.org/) with the [OpenMapTiles schema](https://openmaptiles.org/schema/). Its [quick start](https://openfreemap.org/quick_start/) supports custom styling, and its [terms](https://openfreemap.org/tos/) apply. This replaces the standard OSM raster tile endpoint. The SVG renderer draws water, parks, selected road classes and rail lines, while excluding building footprints, addresses and business labels. Game station and landmark markers are drawn separately.

The client discovers the current tile template from `https://tiles.openfreemap.org/planet`, requests only visible geography, uses the provider's maximum zoom for parent-tile overzoom, and limits its parsed geometry cache to 48 tiles. No offline region downloads or bulk prefetch are implemented. OpenFreeMap, OpenMapTiles and OpenStreetMap credits remain visible and linked. OpenFreeMap's public instance permits commercial use without API keys, but offers no service-level guarantee.

Automated browser tests substitute a small original synthetic vector tile to avoid repeated public-service requests. Their screenshots demonstrate layout and movement, not actual geographic accuracy. A separate bounded live-map check is recorded in the verification artifacts.
